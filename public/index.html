Domain Checker MCP Streamable HTTP

A remote Model Context Protocol server that lets Claude (and other MCP clients) check whether a domain name is available for registration.

MCP endpoint
https://THIS-HOST/mcp

Add it to Claude

  1. Open Claude → Settings → Connectors (or Feature preview / MCP).
  2. Click Add custom connector.
  3. Name: Domain Checker. URL: the endpoint shown above.
  4. Save, then enable it in a chat and ask: “Check whether perfectreview.ai is available.”

Claude Code / Cursor

claude mcp add --transport http domain-checker https://THIS-HOST/mcp

Quick test

curl -s -X POST https://THIS-HOST/mcp \
  -H 'content-type: application/json' \
  -H 'accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list","params":{}}'
